# lw-panel-design-templates
[Loudest Warning](http://www.loudestwarning.co.uk/) format layout and design templates

This repo contains both Affinity files and PDFs for a variety of Loudest Format panel sizes: 1" NPW, 2" NPW, 3" NPW, and 4" NPW.

Each size contains 6-row and 8-row layouts as well as split layouts in case you want to place parts diagonally.

There are also files with assets for commonly used panel-mount objects, sized for their mounting holes.

### Loudest Warning format

Resources used for specs: [this](http://www.loudestwarning.co.uk/portfolio/4u-modular-specs/) and [this](https://loudestwarning.tumblr.com/LW%20FORMAT).

When you put panel components on the first or last horizontal line of the guide/grid, they'll be centered at 7/8" from the top and bottom edges of the front panel respectively. Really that's 7/8" minus 1mm to conform with the LW spec of 175mm front panel height. That placement is compatible with 5.25" long PCBs.

### Note about these files

Several of the Affinity files have only margins and column guides.

The grid PDFs, I imagine, could be imported into your design software of choice.
